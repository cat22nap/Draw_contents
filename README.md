# Draw_contents

同窓会の余興で使う、番号くじ引きシステムです。
参加者のネーム札に入れた番号を抽選し、会場のスクリーンに映して使います。

## 起動

`open.html` を Chrome などのブラウザで開きます。
スクリーンに映すときは **F11** で全画面表示にします。

## 操作

| 操作 | キー |
| --- | --- |
| 抽選する | くじ引きボタン / **スペース** / Enter / → / ↓ / PageDown |
| 直前の番号に不在マークを付ける／外す | **X** |
| 任意の番号に不在マークを付ける／外す | 抽選済み一覧の数字をクリック |
| 抽選結果をリセット | **Shift + Backspace**（確認ダイアログが出ます） |
| 画面全体の拡大・縮小 | Ctrl + マウスホイール（または Ctrl + / Ctrl −） |

- プレゼン用リモコンの「次へ」ボタンでも抽選できます（多くのリモコンは → か PageDown を送るため）。
- 抽選結果はブラウザに保存されます。再読み込み（F5）やブラウザの再起動をしても、抽選済みの一覧は消えません。
- 画面にリセットボタンはありません。開発者ツール（F12）のコンソールで `resetDraw()` と入力してもリセットできます。
- 当選者がその場にいなかったときは、**X で不在マーク（灰色の取り消し線）を付けてから、もう一度抽選** します。
  引いた番号は一覧に残るので、あとから見直せます。間違えたときは、もう一度 X か、一覧の数字をクリックすると外れます。
- 不在マークも保存されます。リセットすると一緒に消えます。
- マウスカーソルは、抽選中とマウスを 2 秒動かさなかったときに自動で隠れます（動かすと表示されます）。

## 本番前の手順

1. `js/script.js` の先頭にある設定を確認します。
   - `START_NUMBER` / `END_NUMBER`：番号の範囲
   - `EXCLUDED_NUMBERS`：除外する番号（事前申告はあったが来なかった人の番号）
2. `open.html` を開き（すでに開いていれば F5）、**Shift + Backspace でリセット** します。
   リハーサルで引いた番号も保存されているため、必ずリセットしてから始めてください。
3. くじ引きボタンの下に「残り ○ 人」を出したい場合は `SHOW_REMAINING = true` にします。

## 設定一覧（js/script.js の先頭）

| 設定 | 内容 |
| --- | --- |
| `START_NUMBER` / `END_NUMBER` | 抽選する番号の範囲 |
| `EXCLUDED_NUMBERS` | 抽選から除外する番号 |
| `MAX_ROW` | 抽選済み一覧で、縦に並べる個数 |
| `SHUFFLE_INTERVAL` | 抽選中に数字を切り替える間隔（ミリ秒） |
| `DRAW_DURATION` | 抽選開始から番号が決まるまでの時間（ミリ秒） |
| `SHOW_REMAINING` | 残り人数を表示するか（true / false） |
| `SAVE_RESULTS` | 抽選結果を保存・復元するか（true / false） |
| `DRAW_KEYS` | 抽選に使うキー |
| `SOUND_ENABLED` | 効果音を鳴らすか（true / false） |
| `DRUMROLL_FILE` / `RESULT_FILE` | 抽選中の音 / 決まった瞬間の音のファイル（空 `''` なら合成音） |
| `DRUMROLL_VOLUME` / `RESULT_VOLUME` | それぞれの音量（0〜1） |
| `REVEAL_ANIMATION` | 番号が決まった瞬間に数字を拡大するアニメーションを出すか（true / false） |
| `ABSENT_MARK_ENABLED` | 不在マーク機能を使うか（true / false） |
| `ABSENT_KEY` | 不在マークのキー（初期値は X キー） |
| `HIDE_CURSOR` | マウスカーソルを自動で隠すか（true / false） |
| `CURSOR_HIDE_DELAY` | マウスを止めてからカーソルを隠すまでの時間（ミリ秒） |

## 効果音

- 抽選中はドラムロール、番号が決まった瞬間に「ジャジャン！」が鳴ります。
- 音源ファイルは再配布できないフリー素材のため、**リポジトリには含めていません**（`src/` フォルダは `.gitignore` で除外）。
  新しい PC で使うときは、フリー音源サイトからダウンロードして次の場所に置いてください。
  - `src/sound/ドラムロール.mp3`（抽選中に流すドラムロール。最後の「ジャン」が入っていないもの）
  - `src/sound/jaja.mp3`（決まった瞬間の「ジャジャン！」）
- 別の名前のファイルを使うときは、`DRUMROLL_FILE` / `RESULT_FILE` のパスを書き換えます。
  ファイルが無い場合は音が鳴らないだけで、抽選はそのまま動きます（パスを `''` にすると合成音になります）。
- ドラムロールは番号が決まった瞬間に止まります。抽選時間（`DRAW_DURATION`）より短いファイルは繰り返し再生されます。
- 音のバランスは `DRUMROLL_VOLUME` / `RESULT_VOLUME` で調整します（決定音を目立たせたいときはドラムロール側を下げる）。
- 会場では、PC の音の出力先が会場のスピーカー（HDMI など）になっているか確認してください。

## 会場での見た目の調整

`css/styles.css` の先頭にある `:root { ... }` の中だけを書き換えます。
保存して F5 を押すと反映されます（抽選結果は消えません）。

- `--size-...`：文字の大きさ（当選番号・一覧・ボタンなど）
- `--color-...`：色（背景・文字・最新の番号・ボタン・決まった瞬間の当選番号・不在マークなど）
- `--reveal-duration` / `--reveal-scale`：決まった瞬間のアニメーションの長さ / いちばん大きくなったときの倍率

プロジェクターだと色が薄く見えることが多いので、文字色を濃くしたり、最新番号の色を鮮やかにしたりして調整します。
