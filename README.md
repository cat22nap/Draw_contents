# Draw_contents

同窓会の余興で使う、番号くじ引きシステムです。
参加者のネーム札に入れた番号を抽選し、会場のスクリーンに映して使います。

## 起動

`open.html` を Chrome などのブラウザで開きます。
スクリーンに映すときは **F11** で全画面表示にします。

## 操作

| 操作 | キー |
| --- | --- |
| 抽選する | くじ引きボタン / **スペース** / Enter / → / ↓ / PageDown |
| 抽選結果をリセット | **Shift + Backspace**（確認ダイアログが出ます） |
| 画面全体の拡大・縮小 | Ctrl + マウスホイール（または Ctrl + / Ctrl −） |

- プレゼン用リモコンの「次へ」ボタンでも抽選できます（多くのリモコンは → か PageDown を送るため）。
- 抽選結果はブラウザに保存されます。再読み込み（F5）やブラウザの再起動をしても、抽選済みの一覧は消えません。
- 画面にリセットボタンはありません。開発者ツール（F12）のコンソールで `resetDraw()` と入力してもリセットできます。
- 当選者がその場にいなかったときは、そのままもう一度抽選します（引いた番号は一覧に残ります）。

## 本番前の手順

1. `js/script.js` の先頭にある設定を確認します。
   - `START_NUMBER` / `END_NUMBER`：番号の範囲
   - `EXCLUDED_NUMBERS`：除外する番号（事前申告はあったが来なかった人の番号）
2. `open.html` を開き（すでに開いていれば F5）、**Shift + Backspace でリセット** します。
   リハーサルで引いた番号も保存されているため、必ずリセットしてから始めてください。
3. くじ引きボタンの下に「残り ○ 人」を出したい場合は `SHOW_REMAINING = true` にします。

## 設定一覧（js/script.js の先頭）

| 設定 | 内容 |
| --- | --- |
| `START_NUMBER` / `END_NUMBER` | 抽選する番号の範囲 |
| `EXCLUDED_NUMBERS` | 抽選から除外する番号 |
| `MAX_ROW` | 抽選済み一覧で、縦に並べる個数 |
| `SHUFFLE_INTERVAL` | 抽選中に数字を切り替える間隔（ミリ秒） |
| `DRAW_DURATION` | 抽選開始から番号が決まるまでの時間（ミリ秒） |
| `SHOW_REMAINING` | 残り人数を表示するか（true / false） |
| `SAVE_RESULTS` | 抽選結果を保存・復元するか（true / false） |
| `DRAW_KEYS` | 抽選に使うキー |

## 会場での見た目の調整

`css/styles.css` の先頭にある `:root { ... }` の中だけを書き換えます。
保存して F5 を押すと反映されます（抽選結果は消えません）。

- `--size-...`：文字の大きさ（当選番号・一覧・ボタンなど）
- `--color-...`：色（背景・文字・最新の番号・ボタンなど）

プロジェクターだと色が薄く見えることが多いので、文字色を濃くしたり、最新番号の色を鮮やかにしたりして調整します。
